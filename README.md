- Создание pyproject.toml
Для того, чтобы создать `pyproject.toml` в корне проекта
создайте `Dockerfile`

```
FROM python:3.13-alpine3.23
ENV POETRY_VERSION=2.4.1 \
    POETRY_HOME="/opt/poetry"
WORKDIR /app
RUN apk add curl
RUN curl -sSL https://install.python-poetry.org | python3 -
```

- выполните команды `docker build -t poetry .` и `docker run -v ./:/app poetry:latest poetry init`


### Требования к фронтенду

1. Многостраничное приложение. Например: Главная, Каталог (с пагинацией),
 Страница товара (от 100), Профиль пользователя, Страница Оформления Заказа,
Похожие товары (после покупки), Админ панель
2. Реализовать на react router (без перезагрузки). Проверить что есть заход на страницу по адересу. Проверить работоспособность с выключенным JS.
3. Некоторый функционал доступен только админу (например кнопка удалить товар)
4. UI - подобраны цвета, шрифты. 
5. Должна быть возможность сменить тему (светлая/темная) и язык (русский/английский/на выбор)
